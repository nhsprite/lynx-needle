# Needle Host (iOS example)

Minimal Lynx host app showing how to integrate `packages/lynx-needle/ios/` and load the
frontend demo bundle (`examples/lynx-needle-demo`).

## Build & run

```bash
# at the repo root — one-time or after addon changes
npm install                   # installs workspace build tooling
npm run fetch-engine          # fetches the pinned Needle engine archives
npm run build:ios             # -> packages/lynx-needle/ios/ artifacts
(cd examples/lynx-needle-demo && npm install && npm run build)

# here
npm install                   # links node_modules/lynx-needle to packages/lynx-needle
bundle install                # installs the pinned CocoaPods and AutoLink plugin
bundle exec ruby generate-project.rb
bundle exec pod install
open NeedleHost.xcworkspace   # build & run on a device or simulator
```

The host prefers the bundled demo template
(`examples/lynx-needle-demo/dist/main.lynx.bundle`) on startup. For local
development and simulator automation, pass a remote demo bundle URL such as
`http://<your-ip>:3001/main.lynx.bundle` with `NEEDLE_BUNDLE_URL` or `--url`.

## How it works

- `AppDelegate.mm` — performs normal Lynx app startup only; addon registration
  is generated by CocoaPods AutoLink
- `ViewController.mm` — builds a plain `LynxView` and loads the fetched
  template
- `package.json` — links the local `packages/lynx-needle` package into
  `node_modules`, where AutoLink discovers its `lynx.lib.json`
- `Gemfile` — pins CocoaPods and `cocoapods-lynx-library` to the versions used
  by this example
- `cocoapods-lynx-library` — scans the local `lynx-needle` npm dependency,
  adds the `lynx-needle` pod, installs the PrimJS weak Node-API bridge, and
  generates `LynxGeneratedNodeAPIAddonUse.mm`
- The pod (`packages/lynx-needle/ios/`) provides the xcframework and `addon_use.h` retention helper

## Notes

- The Podfile pins `pod 'Lynx',
  '4.3.0-nightly.202609090610.180.g5e30c9e6'` from
  `https://github.com/lynx-family/Specs.git`. That podspec downloads the
  published zip from `artifacts-storage.tos-s3-ap-southeast-1.bytepluses.com`.
- Run CocoaPods through `bundle exec`; a globally installed plugin is not
  required.
- `generate-project.rb` only creates the Xcode project once; delete
  `NeedleHost.xcodeproj` to regenerate.
